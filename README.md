# Paulo Inox 🔩

Landing page desenvolvida para a Paulo Inox, com o objetivo de apresentar a empresa, seus serviços e trabalhos realizados em aço inoxidável.

## 💻 Tecnologias

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Apresentação da empresa
- Seção de serviços
- Portfólio de trabalhos
- Design responsivo
- Animações e efeitos de interação
- Área de contato e solicitação de orçamento

## 🔧 Serviços apresentados

- Corrimãos e guarda-corpos
- Peças e estruturas em inox
- Serviços para lanchas e embarcações
- Soldas
- Projetos sob medida

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo computadores, tablets e celulares.

## 🚀 Projeto

Este projeto está sendo desenvolvido como uma landing page para apresentação dos serviços e trabalhos da Paulo Inox.
